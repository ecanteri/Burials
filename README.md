__Cultural affiliation accounts for most of the spatiotemporal variation in burial rite practices__

This is the github repository with code and data associated to the manuscript Canteri et al. (2026) _Cultural affiliation accounts for most of the spatiotemporal variation in burial rite practices_ __bioRxiv__ https://doi.org/10.64898/2026.05.25.725982.

The repository contains a Data folder, a Results folder and a Scripts folder. The .Rmd files in the Scripts folder follow all the different steps, from data processing to data analysis. The INLA models of burial side were run in a HPC computer and were run following the FinalModels.R file. Model performance and cross-validation is run in the files Permutations.R and Culture_permutations.R. The generation of figures was done using the Figures.R and the SupplementaryFigures.R files.
