Cultural hitchhiking: burial rites and genomic variation in space and time

Chapter 1 Burial data

Here we are going to track the analysis on the data that Robert and Stephen shared with us.

We want to explore whether we can find a relationship between large scale human migrations and changes in burial practices during he Holocene.

We will analyse burial practices data against a Gaussian spatial process and values of human ancestry and mobility. The data we have are records of different burial types at grave sites across Europe.

Let’s first input the data. We are going to transform characters to factors for the explanatory variables we need, so we can check how many levels they have.

As we can see, some of the variables we are most interested in, such as the positioning of the body and the burial side, have more than 2 levels. This means that there are more than 2 descriptors for each variable. This makes it tricky because we cannot model factors with more that 2 levels. Therefore, we will create new columns in the database where we transform the factors to a binomial presence/absence data (0/1).

Also, for the Burial Side variable, we have a level called “left?” in the original data table, what should we do with this? Can we group this with the left or not? For now I grouped it because it consists of just 5 records, but we can decide later whether we should keep it separate or not.

1.5.1 Radius approach

Here we extract 3-4 closest individuals within a 350 km radius and up to 300 years apart. If there is only 1 individual, I take the value for that one. If there are two, I take the average mobility value for those two, same for up to 4 individuals.

d <- apply(spatdists, 1, function(x) which(x <= 350))
t <- apply(tempdists, 1, function(x) which(x <= 300))

prod <- lapply(1:length(d), function(x) which(d[[x]] %in% t[[x]])) # match between spat and temp
prod_idx <- lapply(1:length(prod), function(x) d[[x]][prod[[x]]]) # get index
# Sort distances to get the smallest within the 400 km+yrs spatiotemporal radius
dists <- lapply(1:length(prod_idx), function(i) {
  v <- st_dists[i, prod_idx[[i]]]
  names(v) <- prod_idx[[i]]
  return(sort(v))
  })

mob_ids <- lapply(1:length(dists), function(x){
  if(length(dists[[x]]) >= 1){
    ix <- as.numeric(names(dists[[x]]))[1:4]
    ix <- ix[!is.na(ix)]
    return(mobility$Sample_ID[ix])
  } else {
    return(NA)
  }
})

## Extract mobility values
# MDS
mds_dist <- pbsapply(mob_ids, function(x){
  d <- mobility[Sample_ID %in% x]
  if(nrow(d) > 1){
    return(mean(d$ov_dist_mds2_retro_default, na.rm = T))
  } else if(nrow(d) == 1){

                    nrow = length(gr_pnts$YearBP), 
                    ncol = length(ance_pnts$TIME))

# spatiotemporal distances (euclidean with km == year)
st_dists <- sqrt((spatdists + tempdists)^2)

# Find minimum spatial distance
min_columns <- apply(st_dists, 1, find_min)
min_dists <- apply(st_dists, 1, min)

# Get individual ID from ancestry table
ids <- lapply(min_columns, function(x) ancestry$IND[x])

# Extract ancestry value
ance <- paste0("ANCE", 1:9)
anc_vals <- rbindlist(pblapply(ids, function(x){
  d <- ancestry[IND %in% x]
  if(nrow(d) > 1){
    return(as.data.table(matrix(colMeans(d[, ..ance], na.rm = T), nrow = 1, dimnames = list(NULL, ance))))
  } else {
    return(d[, ..ance])
  }
}))

## Method 2: average across the 4 closest individuals within a 350 km and 300 years radius. This threshold has been chosen to minimize the loss of data (only 16% now are not paired with an ancestry value)
d <- apply(spatdists, 1, function(x) which(x <= 350))
t <- apply(tempdists, 1, function(x) which(x <= 300))

prod <- lapply(1:length(d), function(x) which(d[[x]] %in% t[[x]])) # match between spat and temp
prod_idx <- lapply(1:length(prod), function(x) d[[x]][prod[[x]]]) # get index
# Sort distances to get the smallest within the spatiotemporal radius
dists <- lapply(1:length(prod_idx), function(i) {
  v <- st_dists[i, prod_idx[[i]]]
  names(v) <- prod_idx[[i]]
  return(sort(v))
  })

ance_ids <- lapply(1:length(dists), function(x){
  if(length(dists[[x]]) >= 1){
    ix <- as.numeric(names(dists[[x]]))[1:4]
    ix <- ix[!is.na(ix)]
    return(ancestry$IND[ix])
  } else {
    return(NA)
  }
})

## Extract ancestry values
ance_lookup <- ancestry[, .(IND, ANCE1, ANCE2, ANCE3, ANCE4, ANCE5, ANCE6, ANCE7, ANCE8, ANCE9)]
ance_v2 <- rbindlist(pblapply(ance_ids, function(x){
  d <- ance_lookup[IND %in% x]
  if(nrow(d) > 1){
    return(as.data.table(matrix(colMeans(d[, ..ance], na.rm = T), nrow = 1, dimnames = list(NULL, ance))))
  } else if(nrow(d) == 1){
    return(d[, ..ance])
  } else {
    return(data.table(ANCE1 = as.numeric(NA), 
                      ANCE2 = as.numeric(NA), 
                      ANCE3 = as.numeric(NA), 
                      ANCE4 = as.numeric(NA), 
                      ANCE5 = as.numeric(NA), 
                      ANCE6 = as.numeric(NA), 
                      ANCE7 = as.numeric(NA), 
                      ANCE8 = as.numeric(NA), 
                      ANCE9 = as.numeric(NA)))
  }
}))
