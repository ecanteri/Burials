4.1.2 Angular distance

Here we create a function to calculate the distance between two angles, taking into account that angles can cross zero.

# Function to calculate smallest angular distance
angular_distance <- function(a, b) {
  diff <- abs(a - b) %% 360
  return(min(diff, 360 - diff))
}
# Example
angular_distance(350, 10)
## [1] 20
angular_distance(190, 0)
## [1] 170
# Calculate distances
dist_left_right <- angular_distance(as.numeric(mean_left), as.numeric(mean_right))
dist_left_back <- angular_distance(as.numeric(mean_left), as.numeric(mean_back))
dist_right_back <- angular_distance(as.numeric(mean_right), as.numeric(mean_back))

4.1.4 P-value

Now we shuffle the values of angles for each category and compute the differences in circular means and do a histogram where we plot the differences in circular means against the true difference. Do it for each of the three pairs. Make sure that each group has the same amount of observations.

n <- min(c(length(left_circ), length(right_circ), length(back_circ)))

diffs <- lapply(1:1000, function(x){
  l <- sample(left_circ, n)
  r <- sample(right_circ, n)
  b <- sample(back_circ, n)
  mean_l <- mean.circular(l)
  mean_r <- mean.circular(r)
  mean_b <- mean.circular(b)
  dist_lr <- angular_distance(as.numeric(mean_l), as.numeric(mean_r))
  dist_lb <- angular_distance(as.numeric(mean_l), as.numeric(mean_b))
  dist_br <- angular_distance(as.numeric(mean_b), as.numeric(mean_r))
  return(list(dist_lr, dist_lb, dist_br))
})

diffs_lr <- unlist(sapply(diffs, "[", 1))
diffs_lb <- unlist(sapply(diffs, "[", 2))
diffs_br <- unlist(sapply(diffs, "[", 3))
diffs <- list(diffs_lr, diffs_lb, diffs_br)

## Plot histograms
hist(diffs_lr, breaks = 100, main = "Difference between left and right orientations", xlab = "Angular distance"); abline(v = dist_left_right, col= "red", lwd = 3)

hist(diffs_lb, breaks = 100, main = "Difference between left and back orientations", xlab = "Angular distance"); abline(v = dist_left_back, col= "red", lwd = 3)

hist(diffs_br, breaks = 100, main = "Difference between back and right orientations", xlab = "Angular distance"); abline(v = dist_right_back, col= "red", lwd = 3)

## Calculate p-value
# P = (X + 1) / (N + 1)
obs <- list(dist_left_right, dist_left_back, dist_right_back)
pval <- lapply(1:length(diffs), function(x){
  X <- sum(abs(diffs[[x]]) >= abs(obs[[x]]))
  N <- length(diffs[[x]])
  return((X + 1) / (N + 1))
})

4.4.1 Difference between Corded Ware and Bell Beaker cultures

Here we are going to statistically test for differences in the orientations of Corded Ware and Bell Beaker cultures.

First of all, we look at the summary statistics for the two cultures. We can see that the means (mu) are quite different but the Corded Ware orientations are spread across the whole circle (there is very low concentration). This can be seen both by the rho value (mean resultant length) that is close to 0, and by the variance (var) value that is close to 1 (\(var = 1 - rho\)). The standard deviation runs from 0 to infinity, where higher values indicate a larger dispersion.

We can now try and check for differences in mean direction and concentration compared to a uniform distribution.

4.6 Circular linear regression models

For data that is not categorical (e.g., ancestry and mobility values), we have to use a regression model that is specific to angular data.

This regression models both the mean direction and the dispersion simultaneously. The model assumes that a circular response variable \(\theta\) has a von Mises distribution with concentration parameter \(\kappa\), and mean direction (\(\mu\)) related to a vector of linear predictor variables according to the relationship: \(\mu + 2*atan(\beta*x)\), where \(\mu\) and \(\beta\) are unknown parameters, \(\beta\) being a vector of regression coefficients, and \(2*atan()\) being the link function.

The von Mises distribution is a function of \(\mu\) and \(\kappa\), where \(\mu\) is the mean direction and \(\kappa\) is the concentration parameter. A value \(\kappa = 0\) corresponds to the circular uniform distribution; for \(\kappa > 0\), the density is unimodal and symmetrical about \(\mu\), and increasingly concentrated as \(\kappa\) increases. For \(\kappa \ge 2\) the density at the antipode \(\mu + \pi\) is effectively zero, and the distribution is well approximated by a normal distribution with variance \(1/\kappa\).

We can start with an initial value for \(\beta\), to calculate \(\mu\) and \(\kappa\). These estimates can then be used to update the \(\beta\) value, and then to update \(\mu\) and \(\kappa\), analogously to the ML equations for an independent, identically distributed (i.i.d.) von Mises sample. This cycle is repeated until convergence. If \(\beta = 0\), we have a null model where all observations cluster around a common mean direction \(\mu\). However, as the elements of \(\beta\) become infinite, the use of any monotone link function also leads to a null model with mean direction \(\mu ± \pi\). In such cases, the likelihood will have a peak in the vicinity of zero, and attain a similar magnitude as the elements of \(\beta\) tend to \(± \infty\). The optimization process is simplified if the x are centered at their means.

4.7 Bayesian circular regression with continuous data in bpnreg

We can also try using the same Bayesian regression model that we used for the categories.

For continuous explanatory variables we get a set of parameters, bc, SAM and AS, describing its effect on the circle. The coefficient bc represents the slope of the circular regression line at the inflection point. However, this may not be a representative effect for each dataset, as the inflection point can lie in the extremes of the data or even completely outside the range of the predictor x. Therefore, two additional circular coefficients were developed by Cremers et al. (2018), the slope at the mean SAM and the average slope AS. The coefficient SAM represents the slope of the circular regression line at the average of the predictor and the coefficients AS represents the average slope over all values of x.

If the HPD intervals for all three circular coefficients (bc, SAM and AS) include 0, we do not find evidence that at the inflection point, at the average predictor value and on average the covariate influences the angular error.
